# Bases De Datos
- **MySQL:** Base de datos relacional para persistencia transaccional.
    - `msvc-usuarios`
    - `msvc-eventos`
    - `msvc-ventas`
    - `msvc-entradas`
    - `msvc-notificaciones` (E2)

- **MongoDB:** Base de datos NoSQL orientada a documentos.
    - `msvc-preferencias`

- **Redis:** Almacenamiento en memoria para operaciones de alta velocidad.
    - `msvc-ventas`: stock/cupos y retención temporal de reservas (hecho); fila virtual, posiciones y tokens temporales (E2, pendiente).
